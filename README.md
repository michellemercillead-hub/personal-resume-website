# Personal Resume Website

## Project Description

This project is a responsive personal resume website created using semantic HTML5 and CSS. The website presents my professional summary, work experience, education, and certifications.

The project was designed with web accessibility and WCAG 2.1 AA principles in mind. It uses semantic HTML elements, accessible heading structures, semantic date elements, responsive layouts, and keyboard-accessible navigation.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Responsive Web Design
- Semantic HTML

## Features

- Responsive design for desktop and mobile devices
- Semantic HTML structure
- Accessible navigation
- Sequential heading hierarchy
- Employment dates using the `<time>` element
- Individual jobs organized using `<article>` elements
- Resume sections organized with semantic elements
- Keyboard-visible focus indicators
- Print-friendly CSS

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

You can also use the Live Server extension in Visual Studio Code to view the website.

## Project Files

- `index.html` - Contains the structure and content of the resume.
- `styles.css` - Contains the design, responsive layout, and accessibility styles.
- `README.md` - Contains information about the project.
